# WattWise AI — Smart Energy Intelligence Platform

WattWise AI is a machine-learning-powered household energy dashboard.

## Features
- Household electricity consumption analytics
- Interactive energy charts
- One-hour-ahead power consumption prediction
- Electricity bill estimation
- Random Forest machine learning model

## Technology Stack
- Python
- Pandas and NumPy
- Scikit-learn
- Streamlit
- Plotly

## Dataset
UCI Individual Household Electric Power Consumption dataset.

Source: https://archive.ics.uci.edu/dataset/235/individual+household+electric+power+consumption

The dataset represents one household in France. Forecasts and bill estimates are illustrative.

## Run Locally
Install dependencies using: `pip install -r requirements.txt`

Start the dashboard using: `streamlit run app.py`
